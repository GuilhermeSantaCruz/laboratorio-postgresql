# Laboratório PostgreSQL

Repositório dedicado aos meus estudos e práticas de SQL e PostgreSQL durante minha formação em desenvolvimento backend com Python.

## Conteúdo

Neste repositório estão reunidos exercícios, práticas e pequenos projetos desenvolvidos para consolidar conhecimentos em banco de dados.

Entre os principais conceitos praticados:

* SQL básico e intermediário
* Consultas e filtros
* JOINs e relacionamentos
* Funções de agregação
* GROUP BY e HAVING
* Subqueries
* CASE
* NULL e COALESCE
* DISTINCT
* Chaves primárias e estrangeiras
* Modelagem e relacionamentos entre tabelas

## Projetos

### Biblioteca

Práticas envolvendo um sistema de biblioteca e seus relacionamentos entre tabelas.

### Loja de Informática

Banco de dados simulando uma loja de informática, com clientes, produtos, categorias, pedidos e endereços.

### Plataforma de Cursos

Banco de dados simulando uma plataforma de cursos, com alunos, cursos, instrutores, categorias e matrículas.

## Tecnologias

* PostgreSQL
* SQL
* Git
* GitHub

##  Objetivo

Consolidar meus conhecimentos em bancos de dados relacionais e aplicar SQL em situações próximas às encontradas no desenvolvimento backend.

Este repositório também acompanha minha evolução e servirá como parte do meu portfólio de desenvolvimento backend com Python.
